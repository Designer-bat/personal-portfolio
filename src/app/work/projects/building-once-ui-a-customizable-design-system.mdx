## Overview

**YatraFirst** is a modern mobile bus booking platform designed to make intercity travel in Nepal simple, fast, and convenient.

The application allows users to search for buses by selecting their **departure location, destination, travel date, and number of passengers**. It also provides users with quick access to upcoming trips and special travel offers.

The design focuses on simplicity, clear navigation, and an easy booking experience so users can find and book their journey with minimal effort.

## Key Features

- **Bus Search**: Users can enter their departure and destination locations to find available buses.
- **Travel Date Selection**: Users can select their preferred travel date directly from the booking interface.
- **Passenger Selection**: Allows travelers to specify the number of passengers before searching for available buses.
- **Upcoming Trips**: Displays booked or scheduled trips with important details such as route and departure date.
- **Special Offers**: Highlights promotional deals and discounts to help users save on their bookings.
- **Simple Booking Flow**: The booking process is organized into clear steps, reducing confusion and making travel planning easier.
- **Route-Based Search**: Users can easily search popular routes such as **Kathmandu → Pokhara**.
- **Mobile-First Design**: The interface is optimized for smartphone users, making it convenient to plan trips while traveling.

## Design Approach

The design follows a **clean, modern, and minimal visual style** with a bright lime-green accent color that creates a fresh and energetic travel identity.

The interface uses:

- Rounded cards and input fields
- Clear typography
- Simple travel-related icons
- High-contrast call-to-action buttons
- Organized content sections
- Large, easy-to-use form controls

The main dashboard immediately focuses on the user's primary task: **booking a trip**.

The "Namaste, where are you headed?" greeting creates a friendly experience while directing users toward the booking form.

## User Experience

The main UX goal was to reduce the number of steps required to search for a bus.

Users can enter their **From**, **To**, **Travel Date**, and **Passengers** information from a single booking card and then start their search using the prominent **Search Buses** button.

Below the booking section, users can quickly see their upcoming trips and available offers without navigating through multiple screens.

This creates a dashboard that combines **booking, trip management, and promotions** in one place.

## Challenges and Learnings

One of the key challenges was presenting all the necessary travel information without making the home screen feel crowded.

The solution was to divide the interface into clear sections:

1. **Book Your Trip**
2. **Upcoming Trip**
3. **Special Offers**

Another important consideration was making the booking form easy to understand at a glance. Clearly labeled fields, familiar icons, and large touch-friendly controls help users complete the booking process quickly.

## Technologies Used

- **Figma** — UI/UX design, wireframes, and interactive prototypes
- **React / Next.js** — Front-end development
- **CSS / Tailwind CSS** — Responsive interface styling
- **API Integration** — Bus routes, schedules, and booking data
- **Payment Integration** — Secure online travel payments

## Outcome

YatraFirst provides a simple and modern solution for planning and booking bus journeys.

The final experience allows travelers to **search buses, choose travel dates, manage upcoming trips, and discover special offers** from a single mobile application.

The project demonstrates how a focused mobile-first design can simplify the travel-booking experience while maintaining a clean and visually engaging interface.
